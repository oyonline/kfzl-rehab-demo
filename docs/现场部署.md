# 现场部署：在参赛人的电脑上把演示跑起来

比赛现场用**本地版**，不依赖网络。这份文档是给实际操作那台电脑的人看的。

> 线上版（扣子）只作备份和对外发链接，现场不用它 —— 整个网站都在别人服务器上，
> 现场网络一抖就白屏。

---

## 需要准备的两样东西

| 东西 | 从哪来 | 大小 |
|---|---|---|
| 代码仓库（**含 17 个视频**） | `github.com/oyonline/kfzl-rehab-demo`（私有） | 约 350 MB |

**视频已经在仓库里了**（`public/videos/`，约 313 MB），2026-08-30 起不再单独发压缩包 ——
部署从仓库构建，排除在 git 之外会导致线上永远缺视频。代价是 clone 会慢一些，请预留时间。

万一某个视频文件缺失，页面不会报错，会自动退回图文说明。

## 一次性安装（提前做，别留到比赛当天）

### 1. 装 Node

终端里敲：

```bash
node -v
```

出来 `v18` 以上就行。没有的话去 https://nodejs.org 下载安装包，装 LTS 版本。

### 2. 装 pnpm

```bash
npm install -g pnpm
```

### 3. 拉代码

```bash
git clone https://github.com/oyonline/kfzl-rehab-demo.git
cd kfzl-rehab-demo
```

### 4. 确认视频拉全了

视频随仓库一起下来，不需要解压。但 clone 中断过就可能不全，**务必确认**：

```bash
ls public/videos | wc -l
```

**必须输出 `17`。** 少于 17 说明 clone 没拉完，重新 `git clone` 一次。

### 5. 装依赖并构建

```bash
pnpm install
pnpm vite build
```

## 每次演示前：启动

```bash
bash scripts/run.sh
```

看到这一行就是起来了：

```
Server running on http://0.0.0.0:5000  (AI 未启用，走预设答案)
```

**「AI 未启用」是正确的**，本地版本来就不接大模型，对话走事先写好的答案，断网也能演。

停止：终端里按 `Ctrl + C`。

## 演示怎么开

浏览器开**两个窗口并排**：

| 窗口 | 地址 | 账号 | 密码 |
|---|---|---|---|
| 左：老人 / 家属端 | http://localhost:5000/patient | `chen` | `123456` |
| 右：康复师端 | http://localhost:5000/therapist | `xiaoting` | `123456` |

账号已经预填在登录页上，直接点「登录」即可。

**必须是两个窗口，不能是同一窗口的两个标签页也不行 —— 两个标签页可以，两台电脑不行**（数据存在浏览器里，不跨机器）。

演示主线：左边家属端打卡 → 右边康复师端**自动刷新**，不用手动操作。

## 上台前五分钟自检

按顺序过一遍，任何一条不对就别上：

1. `ls public/videos | wc -l` 输出 **17**
2. `bash scripts/run.sh` 启动无报错
3. 左窗口能登录，今日安排里有 **7 项任务**
4. 右窗口能登录，患者名单第一行是**林奶奶**
5. 左窗口点任意一项「完成打卡」，右窗口的 `x/7` **数字变大**
6. 点开一个训练视频，**画面能播**（不是只有封面图）

第 6 条如果只有封面没有画面，说明视频没解压对，回去看第 4 步。

## 出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 视频点开只有封面 | 视频没解压到 `public/videos/`，或解压后没重新 `pnpm vite build` | 重做安装第 4、5 步 |
| 端口被占用 | 上次没关干净 | 换端口：`DEPLOY_RUN_PORT=5001 bash scripts/run.sh` |
| 两端不联动 | 两个窗口不在同一个地址下 | 都必须是 `localhost:5000`，不能一个 `localhost` 一个 `127.0.0.1` —— 浏览器把它们当两个地方 |
| 康复师端把家属端顶掉 | 不应该发生 | 登录态按标签页隔离，若出现请立刻反馈，这是 bug |

---

## 别做的事

- **别改端口后只改一个窗口** —— 两端必须同一个地址，否则数据不互通，联动直接断
- **别用「文件夹直接打开 index.html」的方式** —— 必须通过 `scripts/run.sh` 起服务，直接开文件路由会失效
- **别在演示前 `git pull`** —— 拉到一半改动可能没构建，上台前一天定版后就不要再动
