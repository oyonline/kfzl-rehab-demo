# ADR 0005 · 文件上传做成模拟，不落盘不上传

- 日期：2026-08-27（v0.2 §4.2）
- 状态：生效

## 背景

家属端有"上传训练视频给康复师看"的场景。真做上传涉及文件存储、
体积限制、格式转码、以及最麻烦的一项 —— 现场万一没备好素材，这一步就演不了。

## 备选

1. **真上传**：完整实现，工作量大，且引入现场故障点。
2. **完全砍掉**：演示链路缺一环。
3. **模拟上传**：取文件名与大小这类元数据，不读内容、不落盘、不传输。

## 裁决

**模拟上传。** 未选择文件时用一个默认文件名，保证现场即使没备好素材也能演示这一步。

## 后果

- 现场零故障点，且不产生任何数据传输 —— 顺带避开了隐私合规问题。
- **必须如实披露**：这是模拟，不能在演示中声称"已真实上传"（见 [0006](0006-不编造医疗数值.md) 同一把尺子）。
- 将来要接真上传，需重新评估存储、鉴权与隐私授权，不是简单替换。
