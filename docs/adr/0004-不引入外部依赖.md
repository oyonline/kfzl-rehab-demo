# ADR 0004 · 不引入外部字体 / 图标库 / CDN

- 日期：2026-08-27
- 状态：生效

## 背景

比赛现场网络不可控。演示过程中任何一次外部请求失败，都会在评委面前留下破绽。

## 备选

1. **用组件库 + 图标库 + Google Fonts**：开发快，视觉现成。
2. **本地安装依赖，构建时打包**：不走 CDN，但仍引入体积与版本风险。
3. **完全不引入**：图标手写内联 SVG，字体用系统字体，样式自建设计令牌。

## 裁决

**完全不引入。** 图标为内联 SVG，字体用系统字体，样式为自建设计令牌 + 组件样式
（无 Tailwind、无 UI 组件库）。

## 后果

- 断网也能完整呈现，这是现场演示的硬要求。
- 代价是所有组件手写，前端工作量显著增加（19 页面 + 14 组件 + 1230 行自建 CSS）。
- 同一条原则后来延伸到视频素材：不能用外部对象存储或 CDN 当视频源，
  直接导致了 [0013](0013-视频进仓.md)。
