# ADR 0003 · 两端必须同源部署

- 日期：2026-08-27 确立；2026-08-30 理由变更、结论不变
- 状态：生效

## 背景

家属端与康复师端是同一个前端应用的两个路由，需要部署到线上供演示与备份。

## 备选

1. **两个域名**：`patient.example.com` 与 `therapist.example.com`，看起来更像两个产品。
2. **同一域名两个路径**：`example.com/patient` 与 `example.com/therapist`。

## 裁决

**同一域名两个路径。**

## 后果

- **原理由（2026-08-27）**：演示数据走 localStorage，跨域名则 localStorage 不互通，
  联动闭环直接断裂，只能退回切图演示。
- **理由变更（2026-08-30）**：数据搬到后端数据库后，上述理由**已不适用**。
  但结论不变 —— 前端以相对路径请求 `/api`，跨域名部署会让所有接口请求打空。
- 这是一条**结论正确但论据过期**的约束。保留本记录正是为了说明这一点：
  后来者若只看到旧理由已失效就放宽约束，会撞上新的失败原因。
