# ADR 0006 · 不编造用药剂量与评估量表分值

- 日期：2026-08-27 确立；2026-08-29 部分填实
- 状态：生效
- 相关代码：`src/data/seed.ts`

## 背景

演示需要一份完整的患者档案。档案里包含评估量表分值与用药方案 ——
这两类是**医疗性数据**，编一个看起来合理的数字，技术上毫无难度。

## 备选

1. **编造合理数值**：档案立刻完整、演示好看。
2. **留空**：档案显示"待录入"，视觉上有残缺。
3. **只填有真实来源的，其余留空并标注**。

## 裁决

**方案 3。** 页面一律不展示无来源的具体数值。

## 后果

- **2026-08-29 部分解除**：甲方交付《林奶奶_康复评估量表汇总》（评估日 2026-07-07，
  由康复师小婷、小周、康复护士小彭实测并署名），四张量表因此填实
  （MMSE 18 / 洼田Ⅱ / MMT 左4右5 / Braden 16）。**本项目未生成任何分值。**
- **用药剂量至今未解除**：甲方模板原文只写「吃降压药（如果医生有开药）」，
  未给剂量。因此 `dose` 保持 `待专业确认`、`confirmed: false`，本项目不生成剂量。
- 为叙事完整而虚构的字段一律标注 `SYNTHETIC`，**勿当作甲方数据引用**。
- 配套口径：不得出现"已由医生确认""已真实接入""已同步医院系统"等冒充生产事实的措辞。
